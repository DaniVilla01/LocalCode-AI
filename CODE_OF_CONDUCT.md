# Código de conducta

Este proyecto busca ser un espacio abierto, útil y respetuoso.

## Comportamiento esperado

- Sé respetuoso con otras personas.
- Acepta críticas constructivas.
- Mantén las discusiones centradas en el proyecto.
- Reporta problemas de seguridad con responsabilidad.

## Comportamiento no aceptado

- Acoso, insultos o ataques personales.
- Publicación de información privada.
- Spam o contenido fuera de tema.
- Propuestas para reducir la seguridad por defecto sin justificación clara.

## Aplicación

Los mantenedores pueden cerrar issues, rechazar contribuciones o bloquear participantes que incumplan estas normas.
